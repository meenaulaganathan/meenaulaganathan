# Meena's Digital Canvas

Create a highly professional, modern, visually impressive personal portfolio website for a B.Tech Information Technology graduate and aspiring software/backend developer.

DESIGN STYLE:

- Use a premium dark-themed design.

- Overall look should be modern, futuristic, elegant, and professional.

- Use a dark background with subtle gradient blurs/glowing orbs.

- Use a sophisticated color palette with dark charcoal/black as the base and tasteful blue, purple, and cyan gradient accents.

- Maintain excellent contrast, readability, spacing, and visual hierarchy.

- Avoid making the design look childish, overly colorful, or cluttered.

- The website should feel like a high-end developer portfolio.

TECH STACK — STRICTLY USE:

- React.js

- Framer Motion for smooth animations and transitions

- Three.js / React Three Fiber for 3D animations and interactive 3D elements

- HTML5 and CSS3

- Do not replace React.js with another framework.

- Do not use unnecessary UI frameworks.

MAIN SECTIONS:

1. Home / Hero

2. About

3. Skills

4. Projects

5. Education

6. Resume

7. Contact

HERO SECTION:

- Create a visually stunning hero section.

- Include a professional introduction:

  "Hi, I'm Meena"

  "B.Tech Information Technology Graduate"

  "Aspiring Software / Backend Developer"

- Add a short professional description.

- Include CTA buttons:

  - View Resume

  - Download Resume

  - View Projects

  - Contact Me

- Add an interactive 3D animated developer-themed icon/object using Three.js.

- The 3D object should have subtle rotation, floating movement, lighting effects, and mouse interaction.

- Add beautiful gradient blurs/glowing elements behind the 3D object.

- Use Framer Motion for text entrance animations, staggered animations, and smooth hover effects.

ABOUT SECTION:

- Create a clean but highly animated About section.

- Include a professional summary about an Information Technology graduate interested in software development, backend development, Java, SQL, and modern technologies.

- Use animated cards or visual elements to highlight strengths.

- Add scroll-triggered animations using Framer Motion.

SKILLS SECTION:

- Display technical skills in attractive animated cards.

- Include categories such as:

  - Programming: Java, C

  - Database: SQL

  - Web: HTML, CSS, JavaScript

  - Development: React.js

  - Tools: Git, GitHub, VS Code

  - Concepts: OOP, Data Structures, Backend Development

- Use animated skill cards, progress-style visual elements, icons, hover effects, and staggered entrance animations.

- Do not use misleading percentage skill levels.

PROJECTS SECTION:

Showcase these projects professionally:

1. Hotel Management System

   - Developed using C.

   - Mention relevant functionality such as managing hotel-related records and operations.

2. AI-Powered Expense Tracker

   - A smart expense tracking application.

   - Highlight expense management, categorization, tracking, and AI-powered features.

3. AI-Based Intelligent System for Skill Gap Identification

   - Machine learning-based system.

   - Identify skill gaps by analyzing user skills and comparing them with required skills.

   - Present the project as an intelligent career/skill analysis solution.

For each project:

- Use an attractive animated project card.

- Include project title, description, technologies, and key features.

- Add a "View Project" button only when a valid project link is available.

- Add 3D/hover interactions where appropriate.

- Cards should have smooth hover transformations, glow effects, image movement, and staggered entrance animations.

EDUCATION SECTION:

- Create a visually attractive animated timeline.

- Display B.Tech in Information Technology.

- Include college/university name and graduation year as editable placeholders if exact details are not provided.

- Use a modern timeline animation when the section enters the viewport.

RESUME SECTION:

- Create a dedicated professional Resume section.

- Add two prominent buttons:

  1. View Resume

  2. Download Resume

- Make the buttons highly interactive with Framer Motion.

- Use a resume preview/card design.

- Make the resume file path easy to replace with my actual resume PDF.

CONTACT SECTION:

- Create a professional contact section.

- Include:

  - Name

  - Email

  - Message

  - Send Message button

- Add social/contact links for LinkedIn and GitHub using placeholders that can easily be replaced.

- Add smooth form animations and validation.

- Include a subtle animated background.

NAVIGATION:

- Create a fixed/sticky modern navigation bar.

- Navigation items:

  Home, About, Skills, Projects, Education, Resume, Contact.

- Navigation should work correctly.

- Each navigation item should smoothly scroll or transition to the correct section.

- The active navigation item should be visually highlighted.

- Add a mobile-responsive hamburger menu.

PAGE TRANSITIONS:

- Navigation and page/section transitions must feel seamless.

- Use Framer Motion for full-page transition effects.

- Give different sections their own animation style while maintaining consistency.

- Examples:

  - Home: cinematic fade + scale

  - About: slide/fade

  - Skills: staggered card reveal

  - Projects: 3D-style reveal

  - Education: timeline animation

  - Resume: smooth scale/fade

  - Contact: elegant slide/fade

- Transitions should be smooth and not excessively slow.

HEAVY ANIMATION REQUIREMENT:

The website should be heavily animated and visually engaging, but still professional.

Use:

- Framer Motion

- Scroll-triggered animations

- Staggered text animations

- Smooth section reveals

- Hover animations

- 3D transforms

- Floating elements

- Parallax effects

- Interactive background effects

- Smooth page transitions

- Animated gradient glows

- Subtle particle effects if performance allows

Do NOT animate every element randomly. Animations should have purpose and create a premium experience.

BACKGROUND:

- Use a dark background.

- Add multiple large gradient-blurred glowing shapes/orbs.

- Gradients should slowly move or pulse.

- Add subtle depth using blur and opacity.

- Avoid distracting the user from the content.

- The background should feel futuristic and premium.

3D REQUIREMENTS:

- Use Three.js / React Three Fiber.

- Add at least one interactive 3D element in the hero section.

- The 3D element should respond subtly to mouse movement.

- Add floating/rotating animation.

- Use lighting and materials to create a polished appearance.

- Keep the 3D scene optimized for performance.

- Provide a fallback for devices that cannot handle WebGL.

RESPONSIVENESS:

- Fully responsive on desktop, tablet, and mobile.

- Animations must remain smooth on mobile.

- Reduce heavy animations automatically on low-performance devices.

- Navigation and buttons must work correctly on touch devices.

PERFORMANCE:

- Optimize Three.js rendering.

- Lazy-load heavy components.

- Avoid unnecessary re-renders.

- Keep animations GPU-friendly.

- Respect prefers-reduced-motion.

- Do not sacrifice usability for animation.

CODE QUALITY:

- Use reusable React components.

- Keep the project structure clean and maintainable.

- Separate components, styles, data, and 3D elements logically.

- Use semantic HTML.

- Make all personal information easy to edit.

- Add clear comments where configuration is required.

- Do not leave broken buttons or fake functionality.

FINAL RESULT:

The final portfolio should look like a premium professional developer portfolio suitable for job applications.

It should communicate:

- Strong technical skills

- Professional personality

- Modern development knowledge

- Project experience

- Attention to UI/UX

- Creativity through 3D and animation

IMPORTANT:

Prioritize professional visual hierarchy and usability even though the website is heavily animated. The animations should enhance the portfolio rather than distract from the content.
